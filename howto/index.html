THE ACTION MENU IN DETAIL

"Workstations" are what I call a dives of a character. Agotha has a workstation, Charles etc. Each workstation has a look defined by me. You can temporary change the appearance of each workstation here. Switch to another Workstation, the user + password for the fake Loginscreen cannot be changed. You can save the current state of all your windows. If you have a scene that requieres rearranging windows or changing colors, save it, and after the take reload it. This is maybe not correctly working when restarting the machine. Be careful. Changes to the look of the Operating system, colors and type of MAC/WIndows/Linux/"Spa". If I pre programmed windows to use for a specific scene, you'll see them here. Those windows are special and are linked to the workstation. However, you can "grab" a window from abother workstation if you must Add, organize, remove shortcuts on the desktop. Add new random windows. If you need a news Look for this workstation, jsut press "w" and "d" a couple of times and your desktop will look like your moms. Some functions can be controlled by keyboard. There are 3 options with which to block those commands, so an actor or actress cannot mistakingly press one.
- lock Every shortcut is allowed.
- lock_open Only shortcuts that are user functions are allowed (like blackout, screensaver, etc).
- do_disturb No shortcuts are allowed.
List of Keyboard commands as PDF here
Super easy is to use the delivered remote keypad. all the numerical functions are available with it, so you can control the desktop from afar.

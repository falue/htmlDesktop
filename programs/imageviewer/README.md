## imageviewer

# URL parameters
```
files=1.jpg|2.jpg           file paths split by '|'. looks for files in the current workstation/files/*. Use
                              full path  "../../NameOfWorkstation" so that other users
                              can load the data ("load another window")
allowZoom=true              lets user zoom into images or videos
disableVideoControls=true   disables video.js video controls
disableThumbs=true 
hiddenBar=true 
autoplay=true 
```

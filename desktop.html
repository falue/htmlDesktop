keyboard Keyboard controls


These shortcuts works everywhere in the OS, but not if you have a text input active (such as a terminal, or while logging in).

The "Display and animations" section work also with the numpad on a full sized keyboard *without* the alt key.

  • META

  • alt+a Action menu
  • alt+c Create new shortcut
  • alt+s Save (overwrite)
  • alt+shift+S Save as new file
  • alt+d Clutter desktop with files
  • alt+w Clutter screen with windows

  • DISPLAY & ANIMATIONS

  • alt+1 or alt+b Blackout screen
  • alt+2 or alt+l Logout animation
  • alt+3 or alt+q Shut down animation
  • alt+4 or alt+x Screensaver
  • alt+5 or alt+g Fullscreen-Greenscreen
  • alt+6 or alt+n Display notification or start action
  • alt+7 or alt+shift+C Clear notification / action
  • alt+8 or alt+k Blue screen of death

  • EDDY-G APP (linux)

  • ctrl+r Reload
  • ctrl+shift+r Force Reload
  • ctrl+shift+i Toggle Developer Tools
  • ctrl+0 Actual Size
  • ctrl++ Zoom In
  • ctrl+- Zoom Out
  • F11 Toggle Full Screen
  • Alt+m Toggle Menu Bar
  • Alt+h Home
  • Alt+Left Arrow History Back
  • Alt+Right Arrow History Forward
